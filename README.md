# 🚀 Asteroids Game

## Remake of an good and old asteroids game in GO 

![img_2.png](img_2.png)

## How to Play

- Movement: ⬅️⬆️⬇️➡️
- Fire: **Space Bar**
- Shield Up: **S**
- HyperSpace: **H**

## How to Launch

### 1. On your machine

```shell
make run
```

### 2. In the browser

```shell
make build-wasm
make serve
```
