# 🚀 Asteroids Game

## A remake of an old, good asteroids game in GO

![img.png](img.png)

## How to Play

- Movement: ⬅️⬆️⬇️➡️
- Fire: **Space Bar**
- Shield Up: **S**
- HyperSpace: **H**

## How to Launch

### 1. Play Online

**🎮 [Play the game here!](https://and-ratajski.github.io/go-asteroids/)** 

### 2. On your machine

```shell
make run
```

### 3. In the browser locally

```shell
make serve-wasm
```

Then open `http://localhost:4000` in your browser.
